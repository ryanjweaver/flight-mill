# Flight Mill media

These are direct captures of the Flight Mill GUI from the Windows release
`v0.2.0-preview.1` (`windows-20260915-public1`), captured on 2026-09-15
through its supported browser interface.

- `flightmill-main.png`: trial workspace during the demo.
- `flightmill-simulation.gif`: approximately 24 seconds of the live simulation,
  played at its original speed and looped.

The built-in **Rise & fall** simulation used a base rate of 2 revolutions/second,
seed 42, a 10 cm arm radius, and the default 150 ms minimum accepted interval.
The trial is labeled `DEMO` / `preview` / `SIM-001`. All shown measurements
are synthetic. No physical instrument or research recording was used.

The screenshots preserve the application's rendered content. The animation
uses GIF palette compression. These captures were made by the coding agent
with the owner's explicit permission; they are separate from operator-run
hardware acceptance tests.
