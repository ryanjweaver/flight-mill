# Simulator scenarios

`simulated_device.run_scenario` provides deterministic frames for normal,
zero-event, exact-timing, chatter-boundary, device-reported drop, malformed,
duplicate, skipped-sequence, reset, disconnect/reconnect, and physical-button
start/stop cases.

These scenarios validate software behavior only. They are not evidence of
electrical performance, real sensor timing, development-board fit, or a
fabricated carrier.
